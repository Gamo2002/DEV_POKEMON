# 🤖 IA para Pokémon Fire Red (Projeto de TCC)

Este projeto é um TCC [do curso de XXX da universidade YYY] que visa desenvolver um agente de Inteligência Artificial capaz de jogar Pokémon Fire Red, utilizando apenas captura de tela e processamento de imagem (Visão Computacional) como entrada de dados.

## 🎯 Objetivo

O objetivo principal é criar uma IA que possa navegar pelo mundo, participar de batalhas e tomar decisões estratégicas com base puramente na informação visual da tela do emulador, simulando como um jogador humano perceberia o jogo.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.10+**
* **OpenCV (`opencv-python`)**: Para todo o processamento e análise de imagem.
* **MSS (`mss`)**: Para captura de tela de alta performance.
* **Numpy**: Para manipulação eficiente de arrays de imagem.
* **[Futuramente: Pytesseract]**: Para leitura de texto (OCR).
* **[Futuramente: PyAutoGUI]**: Para simulação de input (teclado).
